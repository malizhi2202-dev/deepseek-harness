# 远端控制与远程资料库：原始需求与裁定

议题 slug：`remote-control-and-sources-2026-09-21`
议题来源：负责人在同一会话中连续提出的三批需求（下附逐字原文），承接 `../sidebar-asks-2026-09-17/` 的右栏能力线。
本议题**不跑完整发现循环**（负责人要求直接接入与验证，未要求再开循环）；本目录只记录：逐字需求、已核实事实、裁定、分阶段路线。

## 一、负责人原文（逐字保留，不改措辞）

1. 「把钉钉，微信，qq，飞书远端控制都接入一下
   这种远端控制在penguin–harness 里边有
   参考一下 同时推推也展示在这个又边栏
   的远端控制里边
   作为插件 展示在右边栏的控制里边
   右边栏的文件不但能打开还能编辑」
2. 「起一个其他端口 验证」
3. 「还有添加远程资料库
   wiki系统  github  百度云  360云 夸克云盘  网易云盘  mysql资料库」

## 二、负责人裁定（本轮，三问三答）

| # | 问题 | 裁定 | 含义 |
| --- | --- | --- | --- |
| R1 | 渠道配置与凭据放在哪一层 | **设置级可编辑** | 用现成 `dsh-settings`（schema 驱动、修订号防并发覆盖）+ `dsh-credentials`（密钥不进配置、只按名字引用）；面板里直接改配置、查凭据状态；**不新增持久化域**。 |
| R2 | 没有官方第三方 API 的网盘怎么办 | **只做官方 API 的源** | GitHub / MySQL / MediaWiki / 百度云官方开放平台照做；360云盘、夸克、网易**明确列为不可用并说明原因**，不写灰色实现。 |
| R3 | 「wiki 系统」先接哪一个 | **先 MediaWiki** | 开放 REST API，公开 wiki 免鉴权、私有 wiki 用 bot 密码；最通用也最易验证。 |
| R4 | 360 系列网盘是否纳入（R2 遗留的问号） | **两项都不做** | 360云盘已停服，360AI云盘虽有官方 Apache-2.0 CLI/MCP 但自标「限时体验/请勿商用」——两者均不接入，按 R2 同一口径在面板说明原因，不写灰色实现。 |

## 三、本议题自行采用的语义假设（未上升为提问，若不符请纠正）

1. **「远端控制」= penguin-harness 的「远程控制」语义**：聊天软件里的消息变成某个 agent 会话的一轮用户输入，助手的完成文本镜像回聊天；扫码/贴码属于获取凭据的交互流程，不是另一套功能。
2. **钉钉是新增平台**，不参考 penguin（其无钉钉，见 `01-verified-facts.md` F7）；钉钉按官方 Stream 模式长连接实现。
3. **「推推」不需要从零写**：本仓库已有 `packages/tuitui/tuitui`，本议题的工作是把它**接入统一通道接缝并展示在右栏面板**。
4. **「右边栏的文件能编辑」是人在 Web 界面的编辑**，不是模型工具（模型侧已有 `tool-str-replace-editor`）。
5. 面板形态沿用右栏既有的 **tab kind + 定义注册**机制（与 git 面板同构），不新造停靠体系。
