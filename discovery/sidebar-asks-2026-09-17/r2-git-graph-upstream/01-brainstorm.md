# R2-5 ① 头脑风暴与调查设计

依据：事实 C2（`@linxin666/dsh-client-ui-git-graph` 已装、被 `disabled`，注释理由 "targets an older DSH API"）、负责人决策 2（"先查上游是否已修 API，能修则启用"）、F29（DSH 无 git 接缝）。

方向：
1. 查上游版本与目标线映射（本议题的执行主体）。
2. 对齐版本线后启用上游最新版（若迁移成本有界）。
3. 留在当前线，核心自建最小只读视图（须标注"有期限的临时物"）。
4. 等待上游出一个匹配当前线的版本。
5. 装与当前线兼容的中间旧版。

明确否决：**硬配中间版本**（映射显示 `^0.1.2-rc.1` 与 `^0.1.5-alpha.2` 之间没有覆盖 `0.1.3-*` 的版本，装上去仍是 API 漂移）；**直接启用已装旧版**（0.2.0/0.13.0 声明的目标是 `^0.1.0-rc.6`，与检出线不符）。
