# R2-B ③ 结论与建议

**总纲**：按钮与命令不是两种实现，而是**同一条命令的两种呈现**；三态落在 `ui-commands` 那条**本来就可区分**的路径上，**冻结的 `{matched: boolean}` 一个字节都不动**。

1. **三态协议**：① 未匹配（`execute` 返回 `undefined`，仅语法/名字不解析）→ 本地即时反馈，**明说"没有这条命令"，并明说"没有留下记录"**；② 被拒（typed RemoteError 的 code + `details.reason`）→ 面板内联 + 本地化外壳；③ 执行失败（`kind:'error'`，宿主已落 `command/done`）→ 内联 + "查看日志"指向**那条**记录。
2. **日志指针规则**：只对 ②③ 出现；① 必须显式说明"没有记录"（今天 `command/run` 尚未追加）。**前置**：类型化结果必须先贯穿，否则 `runDetached` 会把 `matched:false` 折成 `kind:'error'`，客户端分不出 ① 与 ③。
3. **`cancel()` 必须先修**：从 `{accepted:true}` 改为**判别结果**（如 `stopped | nothing-running`），否则"已完成／不是你的／被拒"糊在一起，"什么都没做"无法表达。**它是任何动作上线的前置。**
4. **可用性**：采用 `when`（可否渲染，由面板已持有的事实派生）/ `enablement`（此刻能否执行，本地置灰，**宿主在做出决定的那次操作里重新判定**）的拆分 —— `when` 天然满足 `packages/client/AGENTS.md:36`。**暂不加 `availability` 线字段**（无消费者证据；仓库要求公开选择须先有证据）。
5. **落点**：失败落在**面板内联**（现状 26 处 `role="alert"` / 13 文件），提一个 outcome 原语收敛重复（**落位未决**：放 `ui-primitives` 复用还是各面板自持，见 ④ 与 ⑤）；两条约束：**只渲染宿主已落盘的结果、不得自造状态**；**不得成为绕过 locale 归属的第二条文案通道**。
6. **"什么都没做"语义**：四态区分（已完成／不是你的／被拒／中途失败），`已完成` 走 **info 级**并明确"没有产生变化"，不得写成"失败"。
7. **推荐唯一下一步**：由面板**自己已加载的事实**推导，只暴露一个主行动 + 一句理由；**归因未知时禁用而非仅告警**（GNOME HIG / Apple HIG）。反例警示：`seat-store.ts:109` 在 busy 时**静默返回 `undefined`** —— 正是要避免的静默吞掉。
8. **文案规范**：失败必须说清"谁的动作、什么状态、什么都没做"。

**上线前必须定义**：① 三态结果在客户端各层的类型贯穿（消除 `runDetached` 对「未匹配/执行失败」的合并）；② `cancel()` 判别结果的新返回值及其兼容与迁移路径；③ outcome 原语的落位与它「只渲染宿主已落盘结果」的边界；④ 未本地化文案 `unknown or malformed command: ${line}`（`packages/client/ui-commands/src/client/service.ts:346` 硬编码英文）的归属处理；⑤「什么都没做」四态各自的 level 与文案（locale 拥有）。
