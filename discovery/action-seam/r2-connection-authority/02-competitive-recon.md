# R2-A ② 调查证据（仓库与上游实测 + HEAD/worktree 标注，2026-09-17）

**完整检查链（13 环，按顺序）**：① CLI 只拒通配 bind（`packages/bundle/web-app/src/startup.ts:74-76`）→ ② webserver schema 只允许两个 host 字面量（`packages/host/webserver/src/index.ts:126`；Config 契约 `:60-61`）→ ③ 装配点（`packages/bundle/web-app/cordis.patch.yml:139`）→ ④ load 期 `trustedHosts` 裸 authority 断言（`packages/client/connection/src/index.ts:112` → `api-request-trust.ts:49-53`）→ ⑤ load 期签名密钥（`connection/src/index.ts:117` → `browser-auth.ts:12,171-188`）→ ⑥ 每请求 Host 围栏（`rpc-host.ts:98` → `api-request-trust.ts:99-103`）→ ⑦ cross-site 拒（`api-request-trust.ts:106`）→ ⑧ Origin 必须等于 Host（`:111-117`）→ ⑨ 每请求 cookie 校验（HMAC + authority 绑定 + 寿命；`rpc-host.ts:99` → `browser-auth.ts:300-314`，签名 `:144-169`，cookie 名 `:106-108`）→ ⑩ index 仅 `GET /?token=` 兑换（`browser-auth.ts:250-293`；静态资源公开 `packages/host/frontend-static/src/index.ts:87-91`）→ ⑪ cookie 属性：`HttpOnly; SameSite=Strict; Path=/`，**无 `Secure`**（`browser-auth.ts:132`）→ ⑫ env 逃生门（`browser-auth.ts:120-128`，**在 HEAD 中即为提交状态**，生效于 `:251` 与 `:301`）→ ⑬ 所有 API Proxy / Remote / channel / WS 共用同一认证（`.agents/notes/implemented/architecture/2026-08-24-browser-token-authentication.md:13`；`:43`「持有 cookie 即授权完整工具能力 API」）。

**缺失**：per-session/per-profile 授权；CSRF token；logout/吊销；Secure/TLS；反代与转发头解释；逃生门的文档与告警（全仓**没有任何文档或告警**）；loopback 绑定时 `trustedHosts` 仍被无条件追加且不告警（`packages/bundle/web-app/src/index.ts:134-141`）。

**断链条件（按产品实际行为分类）**：① 第二个本地用户 → 端口可达无 cookie 则 401，**失败得响**；但会话数据依赖 0700/0600（`session-persistence-jsonl/src/index.ts:1124-1128`、`generation.ts:725`、`credentials-local/src/index.ts:699`）而**无人断言** ⇒ 未判定。② 共享 `$DSH_HOME` → 同一签名密钥 + 同一 `$DSH_HOME/sessions` ⇒ **静默放行**（但见下方更正：cookie 本身跨端口不互通）。③ 扩展 `trustedHosts` → 围栏变宽而 cookie 绑 authority ⇒ 新 authority 仍 401，**失败得响**；但一旦在该 authority 访问 `/?token=` 就会为它签发 cookie（`browser-auth.ts:255-277`）⇒ 未判定。④ `DSH_WEB_LOCAL_NO_AUTH=1` → localhost 上**完全绕过 token 与 cookie** ⇒ **静默放行**。⑤ 反代/隧道 → 保留原 hostname 则 403（除非 trusted）＝失败得响；改写成 `127.0.0.1:port` 则围栏通过但远端浏览器不带该 authority 的 host-only SameSite=Strict cookie ⇒ 401；若曾用隧道 URL 兑换过 token 则 cookie 为该 authority 签发且明文传输 ⇒ 未判定。⑥ LAN 绑定 → CLI 路径失败得响，但直接改 cordis 文件为 `0.0.0.0` 会被 `resolveLanTrust` 自动补进 LAN 字面量并**正常运行** ⇒ **只有 CLI 路径失败得响**。⑦ 本地进程/扩展 → 401；叠加 ④ 或 cookie 被窃即全权。

**per-session 授权：不存在。** 一个 cookie 即整个 `ctx.connection` API；会话可见性只按 `header.cwd !== undefined` 过滤（`packages/api/session-controller/src/list.ts:138`，search `:181`），无 owner 也无 profile 过滤，而会话根是跨 profile 共享的 `$DSH_HOME/sessions`（`packages/bundle/base/cordis.patch.yml:113`）⇒ 会话 A 的 cookie 可达会话 B 的数据。已有的 owner 检查只针对 subagent 路由（`session-controller/src/agent.ts:80-90`），不是人类 principal。

**竞品姿态（本轮实测抓取）**：Jupyter 默认开 token、关闭标注 "NOT RECOMMENDED"、且显式区分 Authentication/Authorization 并默认关闭后者（[security](https://jupyter-server.readthedocs.io/en/latest/operators/security.html)、[public-server](https://jupyter-server.readthedocs.io/en/latest/operators/public-server.html)）；Ollama 默认 127.0.0.1，改绑文档**零警告零认证**（[faq](https://docs.ollama.com/faq)）；LM Studio 改绑有 Heads Up 警告并配 token（[serve-on-network](https://lmstudio.ai/docs/developer/core/server/serve-on-network)）；ComfyUI `--listen` 无参数即 `0.0.0.0,::`、无警告无认证（[cli_args.py](https://raw.githubusercontent.com/comfyanonymous/ComfyUI/master/comfy/cli_args.py)）；Docker 的 `docker` 组即 root、未认证 TCP 让 daemon 启动即失败（[postinstall](https://docs.docker.com/engine/install/linux-postinstall/)、dockerd/security 文档源）；VS Code 端口默认 Private、"Public ports don't require sign in" 仅为警告（port-forwarding / remote tunnels 文档）；**WICG Private Network Access：loopback "often assumes protections that simply don't exist"**（[wicg.github.io](https://wicg.github.io/private-network-access/)）。

**产品层的事实**：`scripts/start-web-local.sh:61` 是**已跟踪文件**，以 `env DSH_WEB_LOCAL_NO_AUTH=1` 启动 Web ⇒ 逃生门是**已出货的代码路径**，而非死开关。
